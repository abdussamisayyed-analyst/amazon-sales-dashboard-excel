# 📊 Amazon Sales Dashboard (Excel)

## Project Overview
This project is an interactive Excel dashboard created for Amazon sales analysis.

## Features
- Sales Performance Tracking
- Profit Analysis
- Region-wise Sales Insights
- Interactive Charts
- Pivot Tables & Slicers

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Conditional Formatting
- Slicers
